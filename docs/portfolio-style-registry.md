# Portfolio style registry

The style registry converts eligible local Editor bundles into compact, attributable style families. Each family records source identity, route, protected JavaScript regions, semantic slots, render contracts, hashes, and bounded fragments. Raw portfolio content is not packaged.

Exact reference style has higher precedence than a generic recipe. A standard update may fill declared semantic slots, but it must preserve protected runtime hashes, technology, selectors, layout contracts, and unrelated sections. A stale binding or changed source hash requires a fresh binding and plan.

Large tabs are represented by a synopsis, content hash, and local resource URI. Full `prepare.js` is not returned inline by default. Template migration is a separate explicit intent and is never inferred from a normal update request.
