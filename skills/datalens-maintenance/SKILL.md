# DataLens Maintenance

Paginate inventory completely within the requested scope and describe backup completeness honestly. Before cleanup compute the dependency preserve closure and show the exact delete set. Use documented HTML Page, workbook, access, and license operations only; never invent a revoke route or browser write fallback.

Read [references/boundaries.md](references/boundaries.md) before backup, cleanup, HTML Page, or license work.

Cleanup identity is the provider entry ID regardless of inventory aliases. Preview reads both dependency directions, preserves the original roots, orders consumers before dependencies and rejects incomplete or external-consumer scope. Apply revalidates the original scope before any write; `preview_changed` requires reviewing and confirming the new preview. Failed/uncertain deletion stops all remaining objects and returns per-object skipped/partial effects. Do not retry an uncertain write or recreate deleted objects. A previous authorization covers only its exact scope; a new destructive scope requires current exact confirmation. Preview is bounded to API-visible relations and must not be described as proof of tenant-wide completeness.
